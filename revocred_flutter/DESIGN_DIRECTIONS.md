# RevoCred Design Directions

RevoCred supports two named product themes. They use public interaction and
layout references without copying another product's branding, assets, or exact
trade dress.

## Clear

Clear is the default, light-first direction. It takes inspiration from Wise's
high-clarity consumer-finance hierarchy:

- large financial values and direct next actions;
- generous neutral space with saturated color reserved for decisions;
- plain-language explanations beside estimates and fees;
- friendly rounded surfaces with strong text contrast.

RevoCred keeps its own indigo and violet identity rather than using Wise green.

## Focus

Focus takes inspiration from Linear Mobile's restrained dark product design:

- compact information density and crisp spacing;
- closely layered navy surfaces with subtle borders;
- muted navigation and minimal decorative gradients;
- accent color reserved for current state and primary actions.

## Shared Interaction References

- Apple Wallet informs the selectable vertical card stack. RevoCred uses
  generic card art, explicit preferred status, and visible details rather than
  copying Wallet materials or issuer artwork.
- Perplexity informs Ask REVO's answer-first structure, evidence chips, and
  follow-up prompts. Demo evidence is labeled honestly and is not presented as
  an issuer citation.
- Copilot Money and Robinhood inform the large value hierarchy and compact
  next-action summaries, without speculative or gamified presentation.
- CardPointers and MaxRewards inform card-to-use-now, wallet coverage, benefit
  attention, and fee-review patterns.
- Monarch informs clear settings groups and visible progress/error states.

## Comparing Themes

Run the app, open Profile, and select **Compare themes and components**. On a
wide browser the two concepts render side by side; on mobile they stack. Each
preview includes the same value hero, wallet stack, recommendation, chat
answer, input, actions, and navigation specimen.
