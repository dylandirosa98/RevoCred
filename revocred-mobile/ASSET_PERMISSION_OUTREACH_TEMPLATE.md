# RevoCred Asset Permission Outreach Template

Use this template when requesting permission to display official credit card logos, network marks, and product card artwork in the RevoCred app.

---

## 1) Pre-send checklist

Before sending outreach:

- [ ] Confirm which exact assets you need (logo only vs full card artwork).
- [ ] Confirm ownership (network, issuer, and cobrand if applicable).
- [ ] Prepare app context:
  - App name: RevoCred
  - Platform(s): iOS (+ Android if applicable)
  - Core use case: card search and optimization assistant
  - Asset placement: search result cards, card detail pages, educational comparisons
- [ ] Prepare links/files:
  - Privacy Policy URL
  - Terms of Service URL
  - App screenshots/mockups showing placement
  - Company legal entity name
- [ ] Confirm a dedicated contact email for legal follow-up.

---

## 2) Initial outreach email (copy/paste)

We are requesting permission to use [Brand Name] assets in our app, specifically:

- [ ] Brand/network logo(s)

- [ ] Any required co-brand marks

- Geography: [US only / Global]

## 4) Rights scope checklist for negotiation

Confirm these points in writing:

- [ ] Asset types licensed (logos, card art, names, marks)
- [ ] Territory (US/global)
- [ ] Platforms (iOS/Android/Web/marketing site)
- [ ] Term/expiration
- [ ] Revocation rights
- [ ] Requirement for pre-publication brand review
- [ ] Prohibited contexts (ranking language, endorsements, etc.)
- [ ] Attribution requirements
- [ ] Modification limits (resizing/cropping/backgrounds)
- [ ] Data freshness/disclaimer requirements

---

## 5) Asset ingestion requirements for engineering

Once approved, request assets in these formats if possible:

- Logos: SVG + PNG
- Card artwork: PNG/WebP (2x/3x density if available)
- Brand guide PDF

Ask for explicit written confirmation that RevoCred may:

- cache assets in mobile app bundles
- display assets in search and detail views
- use assets in screenshots submitted to App Store / Play Store
